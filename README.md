# 🌾 AR Farming Educational 

An interactive Augmented Reality (AR) farming experience developed with **Unity**, designed to transform a physical **"FARM" image marker** into an immersive 3D agricultural environment.

The application uses image-target recognition to detect the FARM marker through a device camera and places a virtual farming environment onto the physical surface in real time. The experience demonstrates how Augmented Reality can be applied to educational visualisation and interactive learning.

---

## 📌 Project Overview

Traditional agricultural learning often relies on static images, diagrams and videos. This project explores an interactive AR-based approach where users can view a three-dimensional farming environment directly on a physical marker.

When the camera detects the **"FARM" image target**, the corresponding virtual environment is positioned and tracked over the target.

The AR environment contains a collection of visual farming elements, including agricultural land, vegetation, water resources, farm structures, livestock and farming-related assets.

The project was developed in **Unity** with C# scripting and AR image-target tracking.

---

## 🎯 Objectives

- Develop an interactive AR-based educational experience.
- Demonstrate image-target recognition using a physical FARM marker.
- Overlay a 3D farming environment onto a real-world surface.
- Provide an engaging visual representation of agricultural environments.
- Explore the use of Augmented Reality for educational applications.
- Integrate 3D assets, textures and Unity scenes into an AR experience.

---

## ✨ Key Features

### 🔍 Image Target Recognition
The application detects a predefined **FARM image marker** through the device camera.

### 🌱 3D Farming Environment
Once the marker is recognised, a virtual farming environment is displayed over the physical target.

### 📍 Real-World AR Placement
The virtual environment remains aligned with the detected physical marker while the camera moves.

### 🐄 Agricultural Visualisation
The environment incorporates multiple farming-related 3D elements, including:

- Crops and vegetation
- Farm land
- Water resources
- Livestock
- Farm buildings
- Agricultural structures
- Farming equipment
- Environmental elements

### 🎓 Educational Visualisation
The project demonstrates how AR can be used to make agricultural concepts more interactive and visually understandable.
